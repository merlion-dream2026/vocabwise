# IELTS Speaking Parts 1–3 Integration Decisions

## Included now

- One practice page with selectable Parts 1, 2 and 3.
- Complete curated question bank: 401 Part 1 questions, 60 Part 2 cue cards and 360 Part 3 questions.
- Stable canonical question IDs and server-side resolution.
- Private coursebook reference routes for every question.
- Part-specific evaluation instructions and model-answer length targets.
- Part 2 preparation timer and longer recording window.
- Linked Part 2–3 set navigation.
- Retry and attempt comparison for every part.
- No new package dependency.

## Product decisions retained

- Coach first, scorer second.
- Estimated bands only.
- Model answers at Band 6, 7.5 and 9 using the learner's ideas.
- One model answer using a different idea or story.
- Only 1–3 priority corrections and 3–5 reusable expressions.
- No pronunciation score from transcript alone.
- Reference answers are calibration material and must not be copied verbatim.

## Still deferred

- A single uninterrupted full mock test session.
- Examiner transitions and automatic follow-up selection.
- Saving sessions, transcripts or audio.
- Plan gating and subscription quotas beyond the existing temporary daily call caps.
- Dedicated acoustic pronunciation analysis.
- Teacher review dashboard.
